# Practice Stored Procedures in SQL Server with ASP.NET Core Web API

## Description

This project is designed to practice and understand SQL Server Stored Procedures and how to integrate them with an ASP.NET Core Web API using ADO.NET.

The main objective is to learn how to create, execute, and manage Stored Procedures for database operations such as retrieving, inserting, updating, and deleting student records.

## Practice Objectives

1. Create a SQL Server database and tables.
2. Create Stored Procedures for GET, POST, PUT, and DELETE operations.
3. Pass input parameters from C# to SQL Server Stored Procedures.
4. Connect SQL Server with ASP.NET Core Web API using `SqlConnection` and `SqlCommand`.
5. Execute Stored Procedures using `CommandType.StoredProcedure`.
6. Retrieve database records using `SqlDataReader`.
7. Handle API responses and database errors.
8. Test all CRUD API endpoints using Swagger.

## Technologies Used

- C#
- ASP.NET Core Web API
- SQL Server
- SQL Server Management Studio (SSMS)
- ADO.NET
- Stored Procedures
- Swagger / OpenAPI

## Expected Outcome

Develop a complete Student Management API that performs CRUD operations using SQL Server Stored Procedures and understand how data flows between the Web API, C# controller, stored procedures, and database.
